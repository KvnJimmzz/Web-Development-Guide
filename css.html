CSS3

02 TECHNOLOGY

CSS (Cascading Style Sheets) is the style sheet language used to describe the presentation and visual design of a document structured in HTML. Its primary function is to control the aesthetic aspect of web pages, allowing you to define colors, fonts, spacing, responsive layouts, animations, and visual effects independently from the content structure.

01

BASICS

Inclusion Methods and Basic Syntax

<link rel="stylesheet">

Function: Links an external stylesheet in a separate .css file to the HTML document.

How it works: The browser downloads the CSS file in parallel and applies its rules to the entire document DOM, keeping structure separated from design.

When to use: In any modular, professional web project to facilitate code maintenance and reusability.

Syntax: 

<link rel="stylesheet" href="styles.css">

Internal Styles (<style>)

Function: Embeds CSS rules directly within the <head> tag of the HTML document.

How it works: The rendering engine processes the rules instantly without issuing additional HTTP requests for external style files.

When to use: For quick prototypes, isolated single pages, or declaring critical CSS needed for the initial view.

Syntax: 

<style> body { background-color: #f0f0f0; } </style>

Inline Styles (style attribute)

Function: Applies style properties directly onto a specific HTML element.

How it works: Overrides almost any other external CSS rule due to its high direct specificity on the element.

When to use: Strictly for quick testing or dynamic values injected via JavaScript.

Syntax: 

<p style="color: red; font-size: 16px;">Text</p>

CSS Rule Syntax (Selector + Declaration)

Function: Basic structure composed of a selector and a declaration block enclosed in curly braces.

How it works: The selector identifies target DOM nodes, and the block assigns specific values to their visual properties.

When to use: Whenever writing any instruction or style within CSS.

Syntax: 

selector { property: value; }

02

SELECTORS

Basic Selectors and Combinators

Universal Selector (*)

Function: Selects absolutely every element present in the HTML document.

How it works: Traverses the entire DOM tree, applying the specified properties to each individual node.

When to use: Primarily in global resets for margins, paddings, and the box model (box-sizing).

Syntax: 

* { box-sizing: border-box; margin: 0; }

Type / Tag Selector

Function: Selects all HTML elements that match a specific tag name.

How it works: Searches for a direct match with document tags and applies styles globally to that element type.

When to use: To define base or default styles for global tags like p, h1, a, or body.

Syntax: 

h1 { color: #333; font-family: sans-serif; }

Class Selector (.class)

Function: Selects all elements containing a class attribute with the specified value.

How it works: Allows grouping different elements under a single reusable design entity.

When to use: It is the main recommended method for styling components and elements in CSS.

Syntax: 

.btn { padding: 10px 20px; border-radius: 5px; }

ID Selector (#id)

Function: Selects a single element whose id attribute matches exactly.

How it works: Since IDs must be unique within the document, it applies styles with significantly high specificity.

When to use: Sparingly; preferably reserved for navigation anchors or scripts.

Syntax: 

#main-header { background-color: #111; }

Descendant Combinator (space)

Function: Selects elements that are inside another parent element, regardless of nesting depth.

How it works: Evaluates hierarchy and applies styles to any matching child, grandchild, or distant descendant.

When to use: To style elements contained within specific sections or containers.

Syntax: 

article p { line-height: 1.6; }

Direct Child Combinator (>)

Function: Selects only elements that are immediate, first-level children of a parent container.

How it works: Ignores descendants nested deeper within other sub-containers.

When to use: To style main lists or strict first-level structures.

Syntax: 

ul > li { list-style: none; }

Adjacent Sibling Combinator (+)

Function: Selects the element placed immediately after another element at the same hierarchy level.

How it works: Verifies that both share the same parent and are positioned directly next to each other.

When to use: To add top margins to paragraphs that directly follow a heading.

Syntax: 

h2 + p { margin-top: 10px; }

General Sibling Combinator (~)

Function: Selects all subsequent siblings that share the same parent element.

How it works: Affects any matching element that follows, not strictly the first adjacent one.

When to use: To alter states of multiple elements after interacting with a preceding control.

Syntax: 

h2 ~ p { color: #555; }

03

PSEUDO-ELEMENTS AND CLASSES

Pseudo-classes and Pseudo-elements

:hover

Function: Applies styles when the user hovers over an element with a pointing device.

How it works: Dynamically modifies the visual presentation according to the user interaction state.

When to use: On buttons, links, and interactive cards to provide visual feedback.

Syntax: 

a:hover { text-decoration: underline; color: #007bff; }

:focus and :focus-visible

Function: Styles elements that have received focus via keyboard or direct user interaction.

How it works: Highlights active fields in forms or elements navigated via the Tab key.

When to use: Essential to ensure user interface accessibility.

Syntax: 

input:focus { outline: 2px solid #0056b3; }

:nth-child()

Function: Selects elements based on their position or a mathematical formula within their parent container.

How it works: Accepts numeric indices, keywords (odd, even), or algebraic expressions (2n+1).

When to use: To create striped tables or apply cyclic styles to item lists.

Syntax: 

tr:nth-child(even) { background-color: #f2f2f2; }

:not()

Function: Excludes elements from selection that match the selector passed within its parentheses.

How it works: Filters result sets by omitting elements that satisfy the specified condition.

When to use: To style a set of items while excluding only the first, last, or disabled ones.

Syntax: 

button:not(.btn-disabled) { cursor: pointer; }

::before and ::after

Function: Inserts a decorative pseudo-element before or after the actual content of an element.

How it works: Requires the content property to render a visual element without modifying HTML structure.

When to use: To add icons, graphic decorations, dividers, or complex visual effects.

Syntax: 

.title::before { content: "★ "; color: gold; }

::placeholder

Function: Customizes the appearance of placeholder text inside form input fields.

How it works: Directly modifies the font, color, and opacity of the placeholder attribute on input or textarea elements.

When to use: To ensure guide texts have adequate contrast and align with design systems.

Syntax: 

input::placeholder { color: #888; font-style: italic; }

04

BOXES

Box Model

width and height

Function: Defines the horizontal and vertical dimensions of an element's content area.

How it works: Assigns explicit values measured in pixels, percentages, rem, or other valid CSS units.

When to use: To establish fixed or relative sizes for containers and images.

Syntax: 

.box { width: 300px; height: 150px; }

padding

Function: Sets the inner space between the content and the element's border.

How it works: Expands internal clearance, directly affecting the visible background area of the element.

When to use: To add breathing room around text inside buttons or containers.

Syntax: 

.card { padding: 20px; }

margin

Function: Defines external clearance around the element to separate it from neighboring elements.

How it works: Creates transparent space outside the border to push away surrounding layout elements.

When to use: To separate blocks and sections, or center containers using margin: auto.

Syntax: 

.container { margin: 0 auto 30px auto; }

border

Function: Configures the visual border surrounding the padding and content area of an element.

How it works: Combines width, style (solid, dashed, etc.), and color into a single shorthand property.

When to use: To outline frames, cards, dividers, or form input fields.

Syntax: 

.input-field { border: 1px solid #ccc; }

box-sizing: border-box

Function: Alters how total element width and height are calculated.

How it works: Includes padding and border values within the specified width and height, preventing unexpected size expansion.

When to use: Recommended universally in virtually all modern web projects.

Syntax: 

* { box-sizing: border-box; }

overflow (auto, hidden, scroll)

Function: Controls how content that exceeds its container's boundaries is handled.

How it works: hidden clips overflowing content, scroll adds permanent scrollbars, and auto displays scrollbars only when necessary.

When to use: To prevent unwanted layout breaks or build scrollable content boxes.

Syntax: 

.scroll-box { overflow-y: auto; max-height: 200px; }

05

TEXT STYLES

Typography and Text Properties

font-family

Function: Specifies the typeface or prioritized list of fallback fonts for text content.

How it works: Tries loading fonts sequentially from left to right until finding an available system or web font.

When to use: When defining global or component-specific typographic identities across a site.

Syntax: 

body { font-family: 'Roboto', Arial, sans-serif; }

font-size

Function: Sets the size or scale of text characters.

How it works: Accepts absolute units (px) or relative units (rem, em, %, vw).

When to use: To establish typographic hierarchy between headings, subheadings, and body copy.

Syntax: 

p { font-size: 1rem; }

font-weight

Function: Controls the stroke thickness or bold weight of text characters.

How it works: Accepts numeric values (100 through 900) or descriptive keywords (normal, bold).

When to use: To emphasize keywords, headers, or call-to-action buttons.

Syntax: 

.highlight { font-weight: 700; }

line-height

Function: Sets leading or vertical line spacing within block text elements.

How it works: Distributes extra space evenly above and below characters across each text line.

When to use: To significantly improve readability in multi-line paragraphs.

Syntax: 

p { line-height: 1.5; }

text-align

Function: Dictates horizontal text alignment inside its parent block container.

How it works: Aligns content to the left (left), right (right), center (center), or spreads it evenly (justify).

When to use: To center headlines, right-align table figures, or align body paragraphs.

Syntax: 

h1 { text-align: center; }

text-transform

Function: Controls capitalization styling without modifying underlying HTML text source.

How it works: Transforms character casing to uppercase (uppercase), lowercase (lowercase), or title case (capitalize).

When to use: On buttons, labels, headers, or navigation items.

Syntax: 

.menu-item { text-transform: uppercase; }

06

COLORS

Colors, Backgrounds, and Gradients

color

Function: Sets the foreground color value for text and basic vector icons.

How it works: Accepts keywords, Hexadecimal codes, RGB, HSL, or Oklch color notations.

When to use: To set text readability colors for paragraphs, links, and icons.

Syntax: 

p { color: #2c3e50; }

background-color

Function: Applies a solid, uniform background color behind an element.

How it works: Fills the entire element box, spanning behind content and padding layers.

When to use: To highlight containers, page sections, cards, or main document backgrounds.

Syntax: 

section { background-color: rgba(0, 0, 0, 0.05); }

background-image and linear-gradient()

Function: Assigns external image files or progressive color gradients as element backgrounds.

How it works: Renders raster image assets or dynamically generated gradient layers over the container.

When to use: In hero banners, header backgrounds, or stylized color overlays.

Syntax: 

.hero { background-image: linear-gradient(135deg, #667eea 0%, #764ba2 100%); }

background-size (cover, contain)

Function: Controls scaling behavior and display dimensions of background images.

How it works: cover scales images to fill containers completely (cropping if needed); contain fits entire images without clipping.

When to use: When fitting decorative background assets across varying screen aspect ratios.

Syntax: 

.banner { background-size: cover; background-position: center; }

box-shadow

Function: Casts drop shadow effects around an element's outer border box.

How it works: Accepts X/Y offsets, blur radius, spread distance, and color to simulate visual depth and elevation.

When to use: To add depth and tactile elevation to cards, modals, and interactive buttons.

Syntax: 

.card { box-shadow: 0 4px 6px rgba(0, 0, 0, 0.1); }

opacity

Function: Controls overall transparency levels for an element and all of its children.

How it works: Takes numeric values ranging from 0.0 (completely invisible) to 1.0 (fully opaque).

When to use: For disabled states or fading transition effects during user interactions.

Syntax: 

.overlay { opacity: 0.8; }

07

POSITIONING

Positioning and Document Flow

display (block, inline, inline-block, none)

Function: Determines the formatting box type an element generates within document flow.

How it works: Dictates how elements align relative to neighbors and whether they respect explicit dimensions.

When to use: To override default HTML tag behaviors (e.g., converting an inline link to a block element).

Syntax: 

a.btn { display: inline-block; }

position: relative

Function: Offsets an element relative to its natural position in document flow.

How it works: Accepts directional offsets (top, right, bottom, left) without altering surrounding elements, serving as a reference for absolute children.

When to use: As a positioning anchor for child elements set to position: absolute.

Syntax: 

.parent { position: relative; }

position: absolute

Function: Removes an element from normal flow, positioning it precisely relative to its nearest positioned ancestor.

How it works: Ignores sibling elements, placing itself using explicit coordinate offsets from container edges.

When to use: For badges, pinned icons, tooltips, dropdowns, or decorative UI elements.

Syntax: 

.badge { position: absolute; top: 10px; right: 10px; }

position: fixed

Function: Anchors an element in a fixed position relative to the browser viewport.

How it works: Remains locked on screen in the same location even when the user scrolls through the page.

When to use: For sticky top navigation bars, persistent floating chat widgets, or help buttons.

Syntax: 

.navbar { position: fixed; top: 0; width: 100%; }

position: sticky

Function: Treats an element as relatively positioned until a scroll threshold is met, switching to fixed positioning.

How it works: Toggles positioning modes based on user scroll position within its containing block boundary.

When to use: For sticky table headers, sidebar menus, or table-of-contents widgets during reading.

Syntax: 

.toc { position: sticky; top: 20px; }

z-index

Function: Specifies vertical stacking order along the Z-axis for positioned elements.

How it works: Elements with higher integer values render on top of overlapping elements with lower indices.

When to use: To manage layered components like dropdown menus, modals, and backdrop overlays.

Syntax: 

.modal { z-index: 1000; }

08

FLEXBOX

Flexible Layout (Flexbox)

display: flex

Function: Enables flexible box layout on a container, making its immediate children flex items.

How it works: Establishes primary and cross axes to dynamically distribute free space among items.

When to use: For one-dimensional layouts like navigation bars, row alignment, or column stacks.

Syntax: 

.flex-container { display: flex; }

flex-direction

Function: Defines the orientation of the main axis inside a flex container.

How it works: Arranges flex items horizontally (row) or stacked vertically (column).

When to use: To organize responsive items in rows or switch them into vertical stacks for mobile viewports.

Syntax: 

.flex-container { flex-direction: column; }

justify-content

Function: Aligns flex items along the main axis of the container.

How it works: Distributes remaining free space using options like center, space-between, space-around, or space-evenly.

When to use: To center items horizontally or spread header links evenly across available width.

Syntax: 

.nav-list { justify-content: space-between; }

align-items

Function: Controls flex item alignment along the cross axis (perpendicular to main axis).

How it works: Positions items cross-wise using center, flex-start, flex-end, or stretch.

When to use: To center items vertically within a row of varying element heights.

Syntax: 

.row { align-items: center; }

flex-wrap

Function: Dictates whether flex items are forced into a single line or allowed to wrap onto multiple lines.

How it works: When set to wrap, overflowing items automatically break onto new lines as space shrinks.

When to use: In photo galleries, tag lists, or flexible multi-row grid components using Flexbox.

Syntax: 

.tags-container { flex-wrap: wrap; }

flex (grow, shrink, basis)

Function: Shorthand rule setting a flex item's ability to grow, shrink, or set its initial base size.

How it works: flex-grow sets growth proportion, flex-shrink controls shrink resistance, and flex-basis sets starting width.

When to use: To control proportional stretching or shrinking across flexible columns and sidebars.

Syntax: 

.sidebar { flex: 0 0 250px; } .content { flex: 1; }

09

GRID

Grid Layout (CSS Grid)

display: grid

Function: Enables a two-dimensional grid layout system on the target container element.

How it works: Manages both horizontal alignments (columns) and vertical alignments (rows) simultaneously.

When to use: For building complex page layouts, full application structures, or card galleries.

Syntax: 

.grid-layout { display: grid; }

grid-template-columns and grid-template-rows

Function: Sets explicit tracks, counts, and sizing dimensions for grid columns and rows.

How it works: Accepts fixed lengths, percentages, fractional units (fr), and the repeat() helper function.

When to use: To define column tracks and structural column layouts inside grid containers.

Syntax: 

.grid { grid-template-columns: repeat(3, 1fr); }

gap (column-gap, row-gap)

Function: Sets gutter spacing between grid cells or flex items.

How it works: Inserts clean spacing strictly between items without adding unwanted outer margins around the grid container.

When to use: Modern replacement for traditional outer item margins inside multi-column layouts.

Syntax: 

.grid-container { gap: 20px; }

grid-column and grid-row

Function: Specifies start and end grid line placements for individual child items inside grid tracks.

How it works: Allows elements to span across multiple grid track lines using the span keyword.

When to use: To build feature items, image mosaics, or full-width banner rows inside grid layouts.

Syntax: 

.featured-item { grid-column: span 2; }

grid-template-areas

Function: Maps out grid layouts named by semantic text areas within a visual ASCII layout map.

How it works: Maps layout regions visually using strings that mirror structural grid locations.

When to use: To quickly construct high-level site page layouts (header, sidebar, main, footer).

Syntax: 

.layout { grid-template-areas: "header header" "sidebar main" "footer footer"; }

auto-fit and auto-fill with minmax()

Function: Creates automatically responsive grid track layouts without requiring media queries.

How it works: Dynamically calculates track columns based on specified minimum item widths to fill container space.

When to use: For fluid product catalogs, card layouts, or auto-adapting image galleries.

Syntax: 

.gallery { grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); }

DIMENSIONS TRANSFORMS

2D and 3D Transforms

transform: translate()

Function: Re-positions an element visually along X and Y spatial axes.

How it works: Moves element rendering without affecting surrounding document layout flow or neighbor positions.

When to use: In hover animations, subtle UI interactions, or centering elements precisely with absolute positioning.

Syntax: 

.centered { transform: translate(-50%, -50%); }

transform: scale()

Function: Resizes or scales an element up or down relative to its original size.

How it works: Multiplies original dimensions using a decimal scale factor (e.g., 1.2 = 120% size).

When to use: To create zoom-in visual effects on cards or thumbnail images during hover (:hover).

Syntax: 

.card:hover { transform: scale(1.05); }

transform: rotate()

Function: Rotates an element around a fixed origin point by a specified angular value.

How it works: Applies angular rotation measured in degrees (deg), gradians (grad), or turns (turn).

When to use: To rotate cards, animate UI toggles, flip indicators, or create loading animations.

Syntax: 

.icon-spin { transform: rotate(180deg); }

transform-origin

Function: Sets the origin or anchor point from which element transforms are computed.

How it works: Defaults to the center (50% 50%), but can be moved to any corner or custom coordinate location.

When to use: For clock-hand rotations, swinging doors, or custom unrolling panel transitions.

Syntax: 

.pin { transform-origin: top left; }

perspective and transform-style: preserve-3d

Function: Enables 3D spatial depth and realistic perspective environments for transformed child elements.

How it works: Simulates focal distance between user viewports and 3D planes, projecting points in 3D space.

When to use: In 3D flip cards, rotating cubes, or deep perspective image carousels.

Syntax: 

.scene { perspective: 1000px; } .cube { transform-style: preserve-3d; }

ANIMATIONS

Transitions and Animations (@keyframes)

transition-property and transition-duration

Function: Sets which CSS properties animate smoothly and defines the duration of the transition phase.

How it works: Interpolates intermediate values between initial and final states of a CSS property change.

When to use: To smooth out visual changes like background colors, box-shadows, or transforms upon interaction.

Syntax: 

.btn { transition: background-color 0.3s ease, transform 0.2s ease; }

transition-timing-function (ease, linear, cubic-bezier)

Function: Defines the acceleration curve and pacing during property transition executions.

How it works: Modifies speed curves over time, allowing gradual accelerations or dynamic spring effects.

When to use: To achieve fluid motion and natural-feeling interface transitions.

Syntax: 

.modal { transition-timing-function: cubic-bezier(0.68, -0.55, 0.27, 1.55); }

@keyframes

Function: Declares keyframe steps, sequence stages, and key states of custom CSS animations.

How it works: Defines keyframe checkpoints (expressed as percentages or from/to keywords) along an animation timeline.

When to use: For designing multi-step, complex, or continuously looping visual animations.

Syntax: 

@keyframes pulse { 0% { scale: 1; } 50% { scale: 1.1; } 100% { scale: 1; } }

animation-name and animation-duration

Function: Binds a custom @keyframes sequence rule to an element and assigns its total cycle duration.

How it works: Links animation timeline logic with target DOM nodes and triggers playback using specified durations.

When to use: To trigger custom animations on UI components.

Syntax: 

.loader { animation-name: pulse; animation-duration: 2s; }

animation-iteration-count (infinite) and animation-fill-mode

Function: Dictates cycle repetition counts and defines final property states after animation completion.

How it works: infinite loops animations continuously; forwards retains styles defined in the final keyframe upon ending.

When to use: On loading spinners (continuous loops) or entrance animations (retaining final visible states).

Syntax: 

.spinner { animation: spin 1s linear infinite; }

RESPONSIVE

Media Queries and Responsive Design

@media (min-width / max-width)

Function: Conditionally applies CSS rules based on device viewport features or screen characteristics.

How it works: Evaluates active viewport widths and applies enclosed rules only when matching specified constraints.

When to use: The foundational tool for building responsive layouts across mobile, tablet, and desktop displays.

Syntax: 

@media (min-width: 768px) { .sidebar { display: block; } }

Mobile-First Strategy

Function: Development approach where base styles target small screens first and scale up using min-width queries.

How it works: Optimizes performance by keeping base mobile CSS lightweight and adding complexity progressively for desktop views.

When to use: Universally recommended as a best practice in modern professional web design.

Syntax: 

.col { width: 100%; } @media (min-width: 1024px) { .col { width: 33.3%; } }

@media (prefers-color-scheme)

Function: Detects whether system OS preferences are set to light or dark appearance modes.

How it works: Automatically adapts a website's color theme based on system-level user preferences.

When to use: To provide native, automatic support for Dark Mode styling across your site.

Syntax: 

@media (prefers-color-scheme: dark) { body { background: #121212; color: #fff; } }

@media (orientation: portrait / landscape)

Function: Detects physical device viewport orientation (portrait or landscape modes).

How it works: Checks whether screen width exceeds height (landscape) or vice versa (portrait).

When to use: To adapt mobile app layouts or media views based on device rotation.

Syntax: 

@media (orientation: landscape) { .hero { height: 100vh; } }

Viewport Units (vw, vh, vmin, vmax)

Function: Proportional length units calculated directly as percentages of the visible browser viewport size.

How it works: 1vw equals 1% of viewport width; 1vh represents 1% of total viewport height.

When to use: For full-screen hero sections, full-height panels, or fluid viewport-based typography.

Syntax: 

.full-screen { height: 100vh; width: 100vw; }

13

VARIABLES

CSS Variables (Custom Properties)

Declaring Variables (--my-variable)

Function: Stores reusable CSS values (colors, spacing, fonts) under custom variable names.

How it works: Commonly declared on the :root pseudo-class to ensure global availability across the DOM tree.

When to use: To maintain design system consistency and enable centralized global style updates.

Syntax: 

:root { --primary-color: #3498db; --spacing-md: 16px; }

Consuming Variables with var()

Function: Retrieves and applies stored values from defined custom properties.

How it works: Replaces function calls dynamically with computed variable values during rendering.

When to use: When styling UI components that consume global design tokens.

Syntax: 

.btn-primary { background-color: var(--primary-color); padding: var(--spacing-md); }

Fallback Values in var()

Function: Supplies backup default values if requested CSS variables are undefined.

How it works: The browser renders the secondary parameter if the target variable isn't resolved along the cascade.

When to use: When building isolated standalone components or reusable UI libraries susceptible to missing global tokens.

Syntax: 

.card { color: var(--card-color, #333333); }

Variable Scope and Inheritance

Function: Custom properties respect DOM scoping, allowing contextual overrides within localized containers.

How it works: Re-defines variable values locally inside specific containers without polluting or breaking global scope.

When to use: For contextual themes, localized dark sections, or sub-component variations.

Syntax: 

.dark-zone { --primary-color: #ffffff; }

FILTERS

Filters and Blend Modes

filter: blur()

Function: Applies a Gaussian blur filter effect to rendered element graphics.

How it works: Softens pixel detail across the target element using specified blur radius values in length units.

When to use: For out-of-focus background panels, soft drop shadows, or visual privacy overlays.

Syntax: 

.bg-blurred { filter: blur(5px); }

filter: grayscale(), brightness(), contrast()

Function: Adjusts color tone, saturation, brightness, and contrast rendering on elements and images.

How it works: Dynamically adjusts output color channels on browser-rendered visual layers.

When to use: For black-and-white client logo strips that reveal full color on mouse hover (:hover).

Syntax: 

.logo { filter: grayscale(100%); } .logo:hover { filter: grayscale(0%); }

backdrop-filter

Function: Applies graphical filter effects (like Gaussian blurs) directly to the area sitting behind an element.

How it works: Alters background rendering beneath semi-transparent elements, enabling Frosted Glass (Glassmorphism) effects.

When to use: On translucent floating headers, modal overlays, and modern navigation panels.

Syntax: 

.glass-header { background: rgba(255, 255, 255, 0.2); backdrop-filter: blur(10px); }

mix-blend-mode

Function: Specifies how an element's foreground colors blend mathematically with underlying background content.

How it works: Applies blending algorithms between overlapping visual layers (multiply, screen, overlay, difference).

When to use: For creative typography overlays set across vibrant image backgrounds.

Syntax: 

.overlay-title { mix-blend-mode: difference; color: white; }

15

MATH FUNCTIONS

CSS Math Functions

calc()

Function: Evaluates basic mathematical calculations (addition, subtraction, multiplication, division) to set CSS values.

How it works: Dynamically mixes differing CSS units (e.g., subtracting fixed pixels from percentages) at layout rendering time.

When to use: For calculating dynamic content widths while accounting for fixed sidebars or margins.

Syntax: 

.content { width: calc(100% - 250px); }

min()

Function: Selects the smallest value from a comma-separated list of expressions.

How it works: Sets a maximum cap or upper boundary, ensuring values never exceed specified limits.

When to use: For fluid containers that adapt to mobile viewports while capping max widths on desktop displays.

Syntax: 

.wrapper { width: min(100%, 1200px); }

max()

Function: Selects the largest value from a comma-separated list of arguments.

How it works: Sets a minimum threshold, preventing computed properties from dropping below a baseline size.

When to use: Ensuring typography or internal paddings stay readable and don't shrink excessively on mobile screens.

Syntax: 

.title { font-size: max(18px, 4vw); }

clamp()

Function: Clamps values between defined minimum bounds, preferred fluid targets, and maximum limits.

How it works: Scales fluidly according to screen sizes while locking within explicitly set lower and upper bounds.

When to use: Modern web standard for fluid typography and responsive layout spacing without media queries.

Syntax: 

h1 { font-size: clamp(1.5rem, 5vw, 3rem); }

PROPERTIES

CSS Logical Properties

margin-inline and margin-block

Function: Replaces physical horizontal (left/right) and vertical (top/bottom) margins based on writing mode direction.

How it works: Automatically adapts spacing according to global text writing directions (LTR vs RTL languages).

When to use: For writing internationalization-ready code across multi-language web applications.

Syntax: 

.container { margin-inline: auto; margin-block: 20px; }

padding-inline and padding-block

Function: Defines logical internal padding along inline (horizontal) or block (vertical) layout axes.

How it works: Applies padding at start and end inline directions regardless of physical screen orientation.

When to use: For clean internal spacing inside directional UI components.

Syntax: 

.btn { padding-inline: 16px; padding-block: 8px; }

inline-size and block-size

Function: Logical property replacements for traditional width and height properties.

How it works: inline-size maps to width in horizontal text modes; block-size maps to vertical height.

When to use: In modern logical layouts built for multi-directional text internationalization.

Syntax: 

.box { inline-size: 100%; block-size: 200px; }

17

QUERIES

Container Queries

container-type (inline-size)

Function: Establishes an element as an explicit containment context for descendant container queries.

How it works: Allows child elements to query and adjust layouts according to their immediate parent container width rather than the screen viewport.

When to use: Building modular UI components suitable for reuse inside sidebars or primary content areas.

Syntax: 

.card-wrapper { container-type: inline-size; }

@container Rule

Function: Applies conditional styling rules to elements based on parent container dimensions.

How it works: Evaluates spatial context of ancestor containment contexts instead of global browser viewport sizes.

When to use: Adapting self-contained components (like cards) that alter layout based on where they are placed.

Syntax: 

@container (min-width: 400px) { .card { display: flex; } }

18

AT-RULES

Advanced At-Rules (@layer, @supports)

@layer (Cascade Layers)

Function: Declares explicit cascade layers to systematically manage CSS precedence and specificity order.

How it works: Resolves specificity conflicts cleanly regardless of rule declaration order across external or local files.

When to use: In large applications to isolate base defaults, framework styles, UI components, and utility overrides.

Syntax: 

@layer base, components, utilities; @layer base { h1 { color: blue; } }

@supports (Feature Queries)

Function: Tests browser support for specific CSS property-value pairs before applying enclosed rules.

How it works: Executes enclosed styling rules only if feature testing returns positive browser support.

When to use: Implementing cutting-edge CSS features while providing fallback styles for older user agents.

Syntax: 

@supports (backdrop-filter: blur(5px)) { .glass { backdrop-filter: blur(5px); } }
