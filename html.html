HTML5

01 TECHNOLOGY

HTML (HyperText Markup Language) is the standard markup language used to structure and organize content on web pages. Its main function is to define the elements of a website, such as headings, paragraphs, images, links, lists, and forms. HTML provides the basic structure of a web page.

01

FOUNDATION

Base Structure and Root

The fundamental elements that establish the structure and root of every HTML document.

<!DOCTYPE html>

Function: Serves to inform the browser of the exact version and standard of HTML with which the file was built. It informs the rendering engine about which set of syntactic rules it must apply to process the code in a standardized manner.

How it works: When the browser engine begins parsing the document, this instruction triggers modern standard rendering mode (HTML5 Standard), preventing the browser from entering "Quirks Mode" (compatibility mode for old or legacy code) which would cause unpredictable layout behavior.

When to use: On the very first line of any HTML document or file, before any other tag or space.

Syntax: 

<!DOCTYPE html>

<html>

Function: Serves as the main root container that encapsulates all elements and nodes that make up the web page. It defines the complete scope of the web document.

How it works: The browser takes this tag and creates the main root node within the DOM (Document Object Model) tree structure. All other visual and technical elements are nested hierarchically inside it, also allowing the main language of the document to be declared using the lang attribute.

When to use: In every web project; it must open right after <!DOCTYPE html> and close at the end of the file.

Syntax: 

<html lang="en">...</html>

<head>

Function: Serves to store global configurations, technical links, initial scripts, and document metadata that are not displayed directly on the visual canvas of the page.

How it works: The browser analyzes and processes this block before proceeding to draw the graphical elements. It extracts information about character encoding, external stylesheets to download, required scripts, search engine optimization, and tab titles.

When to use: Mandatorily inside the <html> element, always located before the <body> tag.

Syntax: 

<head><meta charset="UTF-8"><title>Page Title</title></head>

<body>

Function: Serves to house all the structured content and visual interface with which the end user will interact in the browser window.

How it works: The rendering engine processes child nodes inside <body> and applies Layout, Paint, and Compositing algorithms to convert the HTML into visible shapes, text, buttons, images, and interactivity on screen.

When to use: In all HTML documents, immediately after the closing </head> tag.

Syntax: 

<body><h1>Welcome to my website</h1><p>This is the visible content.</p></body>
02

DOCUMENT

Document Metadata and Configuration

Metadata and configuration elements that define how the document is interpreted, indexed, and presented.

<meta charset>

Function: Serves to specify the character encoding map or table that the computer system must use to correctly interpret all the text in the file.

How it works: The browser interprets the bytes stored on the server using the UTF-8 standard, guaranteeing faithful rendering of accents, tildes, punctuation marks, special characters (such as 'ñ'), and international symbols without graphical alterations.

When to use: Always, ideally in the first few lines of the <head> section to prevent prior rendering errors.

Syntax: 

<meta charset="UTF-8">

<meta viewport>

Function: Serves to control and calibrate the scale and dimensions of the display area (viewport) on mobile devices and tablets.

How it works: Instructs the mobile browser to match the width of the logical viewport with the physical screen width of the device (width=device-width) and set the initial zoom level to 100% (initial-scale=1.0), preventing the browser from rendering the page with zoomed-out desktop scaling.

When to use: In the header of any project oriented toward responsive web design.

Syntax: 

<meta name="viewport" content="width=device-width, initial-scale=1.0">

<meta description>

Function: Serves to provide a concise and descriptive summary of the page's purpose or content to search engines and aggregators.

How it works: Search crawlers or bots (like Googlebot) extract this text and frequently use it as the descriptive snippet displayed beneath the title in search engine results pages (SERPs).

When to use: In the header of each individual public page to boost click-through rate (CTR) and SEO optimization.

Syntax: 

<meta name="description" content="Complete and structured guide with all key concepts of HTML5 explained step by step.">

<meta robots>

Function: Serves to transmit explicit indexing and crawling directives to automated search engines.

How it works: Modifies the behavior of engines by indicating whether they should include the page in their public indexes (index/noindex) and whether they should crawl the hyperlinks contained within it (follow/nofollow).

When to use: To prevent indexing of private dashboards, drafts, pages under development, or duplicate policy pages.

Syntax: 

<meta name="robots" content="index, follow">

<meta http-equiv>

Function: Serves to simulate sending HTTP response headers directly from the HTML structure when configuring the web server is not possible.

How it works: The browser interprets the value of the specified property as if it came from the HTTP network protocol, executing actions such as scheduled reloads or rendering compatibility settings.

When to use: To force periodic automatic refreshes, set security policies like CSP, or adjust compatibility modes.

Syntax: 

<meta http-equiv="refresh" content="30">

<title>

Function: Serves to define the official identifying name or title of the document.

How it works: Displays its textual content in the top tab of the browser window, in the operating system taskbar, in navigation history, and as the main title in bookmarks and search engines.

When to use: Mandatorily in all web documents, inside the <head> section.

Syntax: 

<title>Learn HTML5 from Scratch | Professional Handbook</title>

<base>

Function: Serves to set an absolute base URL address from which all relative paths present in the file are resolved.

How it works: When the browser encounters a link or resource with a relative path, it automatically prepends the value specified in the href property of the <base> tag.

When to use: When restructuring massive directories or needing to redirect all fonts and images to a CDN or centralized server.

Syntax: 

<base href="https://cdn.mycompany.com/assets/">

<meta name="keywords">

Function: Serves to list a series of terms and keywords associated with the thematic concept of the page.

How it works: Stores comma-separated descriptors that guided search engines in the early days of the web, although modern search engines no longer take it into account as a direct ranking factor for SEO.

When to use: As internal metadata or for organizational search systems within intranets.

Syntax: 

<meta name="keywords" content="HTML5, web development, programming, frontend, code">

<meta name="author">

Function: Serves to indicate the technical or intellectual authorship responsible for creating the document.

How it works: Allows content management systems (CMS), web archiving systems, and document readers to formally attribute ownership of the content.

When to use: In academic articles, blogs, news publications, and corporate documentation.

Syntax: 

<meta name="author" content="Ana Martínez">

<meta name="theme-color">

Function: Serves to customize the chromatic tone of the browser interface environment on mobile devices.

How it works: Mobile operating systems (such as Android and iOS) adapt the background color of the top status bar and browser navigation bar using the provided hexadecimal value.

When to use: In progressive web applications (PWA) or to reinforce corporate visual identity on mobile devices.

Syntax: 

<meta name="theme-color" content="#2563eb">

<meta property> (Open Graph)

Function: Serves to control how the interactive summary of a page is displayed when linked or shared on social media platforms.

How it works: Crawlers from platforms like Facebook, LinkedIn, or WhatsApp read properties such as og:title, og:image, and og:description to generate an attractive preview card with an image, title, and short text.

When to use: On all public pages likely to be shared by users across social channels.

Syntax: 

<meta property="og:title" content="Complete HTML5 Course">
<meta property="og:image" content="https://site.com/banner.jpg">

<meta name="twitter:card">

Function: Serves to configure the visual format of the rich card when sharing a link on the Twitter/X platform.

How it works: Specifies whether Twitter should structure the outgoing tweet with a small card or a preview with a large highlighted image.

When to use: To optimize the visual impact of content published and shared on Twitter/X.

Syntax: 

<meta name="twitter:card" content="summary_large_image">

RESOURCES

Resource Links and Scripts

Elements used to connect stylesheets, icons, scripts, and other external resources to an HTML document.

<link rel="stylesheet">

Function: Serves to link external CSS stylesheets to the HTML document.

How it works: The browser issues a parallel network request to download the .css file and applies its design and layout rules over the element tree.

When to use: Whenever you wish to apply modular and clean visual styles from independent CSS files.

Syntax: 

<link rel="stylesheet" href="styles/main.css">

<link rel="icon">

Function: Serves to establish the distinctive icon (favicon) of the website.

How it works: The browser downloads the image (in .ico, .png, or .svg format) and renders it next to the window tab and in the bookmarks menu.

When to use: In every web development project to provide visual identity and quick recognition to the site.

Syntax: 

<link rel="icon" href="assets/favicon.svg" type="image/svg+xml">

<link rel="canonical">

Function: Serves to indicate the canonical or original URL of content that may be duplicated across multiple addresses.

How it works: Informs search engines which web address is the legitimate one they should index and rank, consolidating SEO authority into a single source.

When to use: In online stores with products accessible from multiple categories or URL variants.

Syntax: 

<link rel="canonical" href="https://mysite.com/products/blue-shirt">

<script> (Internal)

Function: Serves to write and embed programmatic JavaScript logic directly inside the HTML file itself.

How it works: The JavaScript execution engine temporarily pauses HTML parsing, interprets, and executes the code block immediately.

When to use: For small test scripts or very short initial dynamic configurations.

Syntax: 

<script>console.log("Application initialized successfully.");</script>

<script src> (With defer attribute)

Function: Serves to link an external deferred executable JavaScript file.

How it works: Downloads the script file in the background without interrupting HTML parsing or visual rendering, executing it sequentially once the HTML document has finished building.

When to use: For interface scripts that manipulate DOM elements and require the HTML to be completely constructed.

Syntax: 

<script src="js/app.js" defer></script>

<script src> (With async attribute)

Function: Serves to execute an external script asynchronously as soon as its download completes.

How it works: The browser downloads the script in the background and pauses only for the instant required to execute it as soon as the download finishes, regardless of the HTML loading state.

When to use: For independent scripts that do not depend on the DOM structure or other scripts (e.g., web analytics, advertising banners).

Syntax: 

<script src="https://analytics.com/tracker.js" async></script>

<style>

Function: Serves to embed CSS style rules and properties within the HTML document itself.

How it works: The rendering engine applies the CSS rules written inside it instantaneously when processing the node, without making additional network requests.

When to use: To declare critical CSS necessary for the above-the-fold view or small prototyping tests.

Syntax: 

<style>body { font-family: sans-serif; background-color: #f4f4f9; }</style>
04

SEMANTICS

Semantic Site Structure

Semantic containers that define the structural regions and hierarchy of a web page.

<header>

Function: Serves to structure the top introductory block or header of a page or section.

How it works: Semantically delimits logos, titles, navigation menus, or search engines, informing assistive technology of its introductory nature.

When to use: In the top header of a website or at the beginning of sections and articles.

Syntax:

<header><h1>My Web Portal</h1></header>

<nav>

Function: Serves to encapsulate a section of links with the explicit purpose of offering navigation.

How it works: Allows screen readers and bots to immediately identify primary shortcuts to jump to other areas or pages.

When to use: In primary menu bars, article content indexes, pagination, or footer menus.

Syntax:

<nav><p><a href="#home">Home</a></p><p><a href="#services">Services</a></p></nav>

<main>

Function: Serves to contain the core, unique, and dominant information of the current file.

How it works: Isolates central content, preventing it from being confused with repetitive global blocks like navigation menus or footers.

When to use: Only once per HTML document.

Syntax:

<main><h2>Main Page Content</h2></main>

<section>

Function: Serves to delimit a generic, cohesive thematic section within the document.

How it works: Groups conceptually related information, creating chapters or divisions within the page hierarchy.

When to use: To structure sections like "About Us", "Gallery", or "Contact" that include their own heading.

Syntax:

<section><h2>Our Services</h2><p>Details of IT services...</p></section>

<article>

Function: Serves to encapsulate an independent piece of information that makes semantic sense on its own.

How it works: Allows news aggregators or external readers to extract the block without losing context from the rest of the page.

When to use: In blog posts, newspaper news items, user comments, or product cards.

Syntax:

<article><h2>HTML5 News</h2><p>Published on August 10...</p></article>

<aside>

Function: Serves to present secondary or complementary content tangentially related to the main topic.

How it works: Separates supporting information blocks so that the primary reading maintains its logical flow.

When to use: In sidebars, author bio boxes, advertising, or related links.

Syntax:

<aside><h3>About the Author</h3><p>Senior Web Developer with 10 years of experience.</p></aside>

<footer>

Function: Serves to structure the closure or footer of the site or a section.

How it works: Contains institutional data, copyright information, policy links, and legal notices.

When to use: At the end of the entire document or as a closing block within cards and articles.

Syntax:

<footer><p>© 2026 Digital Company. All rights reserved.</p></footer>

<div>

Function: Serves as a generic block container without any inherent semantic value.

How it works: Groups multiple elements for the sole purpose of applying visual styling through CSS or programmatic manipulation via JavaScript.

When to use: As a layout resource when no appropriate semantic tag exists for the group.

Syntax:

<div class="card-container"><p>Inner content...</p></div>

<search>

Function: Serves to delimit the area or form dedicated exclusively to searches and filtering.

How it works: Semantically identifies the search zone for assistive technologies and modern browsers.

When to use: To wrap global search forms or filtering modules within an application.

Syntax:

<search><form action="/search"><input type="search" name="q" placeholder="Search..."></form></search>
05

TYPOGRAPHY

Headings and Text Hierarchy

Heading elements establish the semantic hierarchy of document content.

<h1>

Function: Serves to declare the primary heading of greatest importance and hierarchy in the document.

How it works: Indicates to the browser and search engines the central and indivisible topic of the web page.

When to use: Once per page as a fundamental descriptive title (although technical HTML5 standards allow multiple <h1> tags if nested within independent sectioning contexts like <article> or <section>).

Syntax:

<h1>Web Architecture Handbook</h1>

<h2>

Function: Serves to mark headings for secondary sections or blocks.

How it works: Subordinates content to the hierarchy of the primary <h1> heading, dividing the topic into organized parts.

When to use: To title each thematically distinguishable section within the document.

Syntax:

<h2>1. HTML Fundamentals</h2>

<h3>

Function: Serves to indicate subsections contained within an <h2> section.

How it works: Creates a third level of semantic breakdown in the text hierarchy.

When to use: To specify specific subtopics within a section.

Syntax:

<h3>1.1 DOM Structure</h3>

<h4>, <h5>, <h6>

Function: Serve to structure deeper levels of hierarchy within complex outlines.

How it works: Organize advanced breakdowns while preserving their respective logical subordination.

When to use: In extensive texts, technical manuals, or scientific documents.

Syntax:

<h4>1.1.1 Global Attributes</h4>

<hgroup>

Function: Serves to group a main heading with its direct subtitles or taglines.

How it works: Consolidates the title and its secondary elements into a single semantic header unit.

When to use: When a headline is accompanied by a subtitle or slogan without computing as a new level in the table of contents.

Syntax:

<hgroup><h1>My Business</h1><p>Innovation within your reach</p></hgroup>
06

TEXT

Paragraphs and Block Text Formatting

Elements for organizing paragraphs, breaks, quotations, and preformatted text.

<p>

Function: Serves to delimit continuous blocks of text or paragraphs.

How it works: Models text by separating it visually using automatic top and bottom margins.

When to use: To write any explanatory text or standard reading material.

Syntax:

<p>This is a paragraph with explanatory information on the subject.</p>

<br>

Function: Serves to produce an immediate line break in text without creating a new paragraph.

How it works: Interrupts the flow of the current line and shifts subsequent text to the next line.

When to use: In poetry verses, song lyrics, or postal addresses.

Syntax:

Main Street #12<br>Madrid, Spain

<hr>

Function: Serves to represent a thematic break or shift within the text.

How it works: Draws a horizontal separating line by default, creating a change of context.

When to use: Between book chapters or abrupt transitions in topic.

Syntax:

<hr>

<blockquote>

Function: Serves to frame an extensive textual quotation from an external source.

How it works: Isolates text by applying block indentation and allowing the source to be cited using the cite attribute.

When to use: When including full quotes from books, articles, or speeches.

Syntax:

<blockquote cite="https://source.com"><p>Simplicity is the key to true elegance.</p></blockquote>

<pre>

Function: Serves to present preformatted text exactly as written.

How it works: Preserves all whitespace, tabs, and line breaks using a monospace font.

When to use: To display source code blocks, text diagrams, or ASCII art.

Syntax:

<pre>Function Start() { Console.Write("Ok"); }</pre>
07

INLINE

Inline Text Formatting and Emphasis

Inline elements for emphasis, highlighting, annotations, and specialized text presentation.

<span>

Function: Generic inline container without direct semantic meaning.

How it works: Encapsulates text selections without interrupting the inline flow to apply styles or manipulate them.

When to use: To customize the visual style of specific words or fragments.

Syntax:

<p>The order status is <span style="color: green;">Approved</span>.</p>

<strong>

Function: Assigns high importance or urgency to a fragment of text.

How it works: Grants high semantic weight for screen readers and renders in bold.

When to use: In warnings, essential terms, and crucial notices.

Syntax:

<p><strong>Warning:</strong> Save your changes before leaving.</p>

<em>

Function: Applies stress emphasis or intonation change to text.

How it works: Alters pronunciation in assisted reading and renders in italics.

When to use: To highlight words that carry the core intent of a sentence.

Syntax:

<p>You must send the report <em>today</em> without fail.</p>

<b>

Function: Visually highlights text without adding extra semantic importance.

How it works: Applies bold styling without altering tone or relevance for accessible assistance.

When to use: Key terms in summaries, product names, or search terms.

Syntax:

<p>The term <b>HTML</b> stands for a markup language.</p>

<i>

Function: Represents text in an alternate tone or voice.

How it works: Displays in italics without implying stress emphasis.

When to use: For Latin phrases, technical terms, scientific names, or thoughts.

Syntax:

<p>The term <i>Status quo</i> is frequently used.</p>

<u>

Function: Marks text with a non-textual visual underline.

How it works: Applies a line beneath text without signifying a hyperlink.

When to use: For spelling annotations or proper nouns in transcripts.

Syntax:

<p>The word <u>receive</u> is spelled with 'ei'.</p>

<del> and <s>

Function: Represent content that has been removed or is no longer accurate.

How it works: Display a strikethrough line over the text; <del> denotes formal document editing.

When to use: In document revisions or price breakdowns in sale offers.

Syntax:

<p>Price: <del>$100 USD</del> $80 USD</p>

<ins>

Function: Indicates a recent addition or insertion of text in a document.

How it works: Underlines text to formally indicate its incorporation into the current version.

When to use: In track changes for contracts, regulations, or articles.

Syntax:

<p>Our main headquarters is in <ins>Madrid</ins>.</p>

<mark>

Function: Highlights text due to its circumstantial or contextual relevance.

How it works: Applies a background highlight (yellow by default) to simulate a highlighter pen.

When to use: To highlight search matches within a page.

Syntax:

<p>Results for 'web': advanced <mark>web</mark> development.</p>

<small>

Function: Represents side comments, disclaimers, or legal fine print.

How it works: Reduces text size to signal lower information weight.

When to use: In copyright notices, terms of use, and explanatory notes.

Syntax:

<small>Applies only to new users. Terms and conditions subject to change.</small>

<sub> and <sup>

Function: Position text as subscript or superscript.

How it works: <sub> lowers and shrinks text; <sup> raises and shrinks text.

When to use: In chemical formulas (H2O), mathematical equations (X2), or footnotes.

Syntax:

<p>Formula: H<sub>2</sub>O | Equation: X<sup>2</sup> + Y<sup>2</sup></p>
08

SEMANTICS

Specialized Text Semantics

Elements that communicate specialized meaning such as code, definitions, citations, dates, and text direction.

<code>

Function: Represents computer code snippets or commands.

How it works: Applies a monospace font to distinguish code instructions from body text.

When to use: To reference functions, variables, or code lines in guides.

Syntax:

<p>Use the <code>fetch()</code> function to retrieve data.</p>

<kbd>

Function: Denotes physical keyboard inputs or voice commands entered by the user.

How it works: Formats text in monospace layout emulating key caps.

When to use: In tutorials instructing keyboard shortcuts.

Syntax:

<p>Press <kbd>Ctrl</kbd> + <kbd>C</kbd> to copy.</p>

<samp>

Function: Represents sample output or response from a system or software.

How it works: Displays text in a terminal font indicating results emitted by an application.

When to use: To show console messages or software errors.

Syntax:

<p>System responded: <samp>500 Internal Server Error</samp></p>

<var>

Function: Defines a mathematical or programming variable within text.

How it works: Renders letters in italics to distinguish them as dynamic or unknown values.

When to use: In explanations of algorithms and mathematical equations.

Syntax:

<p>If <var>x</var> equals 10, determine the result.</p>

<abbr>

Function: Defines abbreviations, acronyms, or initialisms.

How it works: Allows providing an expanded definition via the title attribute, visible on hover or via assisted reading.

When to use: The first time a specialized acronym appears in text.

Syntax:

<p>We study the <abbr title="HyperText Markup Language">HTML</abbr> standard.</p>

<dfn>

Function: Marks the exact term being formally defined within a sentence.

How it works: Indicates to analytical engines the specific keyword being explained.

When to use: In glossaries and technical manuals the first time a concept is defined.

Syntax:

<p>An <dfn>algorithm</dfn> is a finite sequence of logical instructions.</p>

<cite>

Function: References the formal title of a creative or intellectual work.

How it works: Displays text in italics, identifying it semantically as an artistic or scientific work.

When to use: When citing books, paintings, songs, movies, or research papers.

Syntax:

<p>More information in the book <cite>Don Quixote</cite>.</p>

<q>

Function: Inserts a short inline textual quote.

How it works: Automatically encloses content in quotation marks matching the document language.

When to use: For short quotes integrated naturally into a paragraph.

Syntax:

<p>The teacher said: <q>Practice makes perfect</q>.</p>

<time>

Function: Represents machine-readable dates, times, or durations.

How it works: Binds visual text with an ISO 8601 standardized date using the datetime attribute.

When to use: In event dates, notices, comments, or publications.

Syntax:

<p>Published on <time datetime="2026-08-10">August 10, 2026</time>.</p>

<address>

Function: Groups direct contact information for the document author or owner.

How it works: Formats physical addresses, emails, and phone numbers in an identifiable layout.

When to use: In the main page footer or fixed contact sections.

Syntax:

<address>Contact: <a href="mailto:info@company.com">info@company.com</a></address>

<bdi> and <bdo>

Function: Isolate or override default text reading direction.

How it works: <bdi> isolates text of unknown direction; <bdo> forces direction via dir="rtl" or ltr.

When to use: When embedding international text read right-to-left (e.g., Arabic, Hebrew) alongside Western text.

Syntax:

<p>Reversed text: <bdo dir="rtl">This text will read backwards</bdo></p>

<ruby>, <rt>, <rp>

Function: Display small pronunciation annotations above Asian language characters.

How it works: <ruby> delimits the expression, <rt> adds top pronunciation guides, and <rp> provides fallback parentheses for older browsers.

When to use: To guide character reading in Asian languages (such as Japanese Kanji or Chinese Hanzi).

Syntax:

<ruby>漢 <rp>(</rp><rt>かん</rt><rp>)</rp></ruby>

<wbr>

Function: Suggests a safe line break point within very long words.

How it works: Indicates to the browser exactly where it may break character strings if the display becomes narrow.

When to use: In long URLs or compound terms lacking spaces.

Syntax:

https://site.com/section/article<wbr>SuperLongWithDetails.html

NAVIGATION

Links and Hyperlinks

Different ways to navigate between documents, resources, sections, and actions.

<a> (External Link)

Function: Connects and redirects navigation to an external website outside your own domain.

How it works: Requests a new resource over the open network via HTTP/HTTPS protocols.

When to use: To cite external sources or direct users to third-party domains.

Syntax:

<a href="https://www.w3.org" target="_blank" rel="noopener">Visit W3C</a>

<a> (Internal Link)

Function: Navigates between different sections or documents within the same website.

How it works: Loads local or relative file paths without leaving the primary server.

When to use: In navigation menus, inter-page buttons, and indexes.

Syntax:

<a href="/contact.html">Go to Contact</a>

<a> (Internal Anchor)

Function: Scrolls page display directly to a specific section or point in the current document.

How it works: Locates an element whose id attribute matches the value following the # symbol and positions the screen over it.

When to use: In tables of contents at the beginning of long articles or "Back to Top" buttons.

Syntax:

<a href="#faq-section">See FAQ</a>

<a> (mailto / tel Action)

Function: Triggers direct operating system tools such as email clients or telephone dialers.

How it works: Invokes the default device application, passing the address or phone number to initiate interaction.

When to use: Direct support links, helpline numbers, or emails.

Syntax:

<a href="mailto:support@web.com">Send Email</a> | <a href="tel:+34900112233">Call Toll-Free</a>

<a> (Download - download attribute)

Function: Forces the browser to download the linked file instead of navigating to it.

How it works: The presence of the download attribute instructs the navigation engine to trigger a local disk transfer.

When to use: For links pointing to PDFs, ZIP files, APKs, or downloadable assets.

Syntax:

<a href="/files/manual.pdf" download="User-Guide.pdf">Download Manual</a>

<a> (rel and target attributes)

Function: Define window opening destination (target) and security/trust relation (rel).

How it works: target="_blank" opens resources in a new tab. Values rel="noopener noreferrer" secure execution threads to prevent security vulnerabilities (tabnabbing).

When to use: On all external links pointing away from your website.

Syntax:

<a href="https://example.com" target="_blank" rel="noopener noreferrer">Secure Link</a>

MEDIA

Multimedia and Images

Images, responsive media sources, audio, video, and captions.

<img>

Function: Inserts a graphic image directly into the document flow.

How it works: Downloads the image file via the src attribute and renders it preserving specified proportions, requiring mandatory text descriptions via alt.

When to use: To include illustrations, diagrams, photos, or logos.

Syntax:

<img src="landscape.jpg" alt="Snowy mountain at sunrise" width="800" height="600">

<picture>

Function: Provides adaptive image alternatives based on screen capabilities or format support.

How it works: Evaluates media rules (media queries) inside child <source> elements to download only the most efficient image according to device resolution or support.

When to use: To serve modern compressed formats (like AVIF or WebP) with JPG/PNG fallbacks, or adapt images to screen sizes.

Syntax:

<picture><source srcset="photo.avif" type="image/avif"><source srcset="photo.webp" type="image/webp"><img src="photo.jpg" alt="Image description"></picture>

<source>

Function: Specifies alternative media resources for <picture>, <video>, and <audio> elements.

How it works: The browser evaluates srcset, media, or type attributes on each <source> tag sequentially, choosing the first compatible resource.

When to use: Inside multimedia containers to offer varying resolutions or audio/video codecs.

Syntax:

<source srcset="large-image.jpg" media="(min-width: 800px)">

<video>

Function: Embeds video content directly into the document with support for interactive media controls and native playback.

How it works: The browser renders a native video player, allowing video sources specified via the src attribute or nested <source> tags to load and play directly on the page.

When to use: To display promotional clips, product demonstrations, background videos, or local video tutorials directly in the browser.

Syntax:

<video controls width="640" poster="thumbnail.jpg"><source src="video.mp4" type="video/mp4">Your browser does not support the video tag.</video>

<audio>

Function: Embeds sound or audio files directly into the web page without requiring external plugins.

How it works: Loads audio tracks specified through its src attribute or child <source> elements and provides built-in playback controls (play, pause, volume) when the controls attribute is enabled.

When to use: To integrate podcast episodes, background music, audio interviews, or sound effects into your web application.

Syntax:

<audio controls><source src="audio.mp3" type="audio/mpeg">Your browser does not support the audio element.</audio>

<figure> and <figcaption>

Function: Encapsulate self-contained illustrative content alongside its explanatory caption.

How it works: Semantically connects images, diagrams, or code snippets with the explanatory note written inside <figcaption>.

When to use: For schematics, article photos, data charts, or cited code blocks.

Syntax:

<figure><img src="chart.png" alt="2026 Sales Chart"><figcaption>Figure 1: Bi-annual company growth.</figcaption></figure>

DATA

Lists and Data Structures

Ordered, unordered, and descriptive list structures.

<ul>

Function: Creates an unordered list of items without explicit numerical sequence.

How it works: Groups <li> nodes, applying bullet points or graphic symbols to their left by default.

When to use: For lists where factor sequence or order does not alter meaning (e.g., ingredients, features).

Syntax:

<ul><li>Apples</li><li>Oranges</li></ul>

<ol>

Function: Structures a list where sequential or chronological order is fundamental.

How it works: Automatically numbers each child <li> element using numbers, letters, or Roman numerals.

When to use: In recipes, ordered step-by-step tutorials, or rankings.

Syntax:

<ol><li>Step 1: Turn on laptop.</li><li>Step 2: Open browser.</li></ol>

<li>

Function: Defines individual items contained within a list.

How it works: Must be nested inside a list container (<ul>, <ol>) to structure information units properly.

When to use: For every indivisible entry in a list.

Syntax:

<li>List item</li>

<dl>, <dt>, <dd>

Function: Form a description list consisting of terms and descriptions.

How it works: <dl> acts as the main container, <dt> identifies the key term, and <dd> contains the associated definition.

When to use: In glossaries, FAQ sections, or metadata spec sheets.

Syntax:

<dl><dt>HTML</dt><dd>Markup language for creating web pages.</dd></dl>

DATA

Data Tables

Semantic elements for representing structured tabular data.

<table>

Function: Defines a grid matrix structure to present data in rows and columns.

How it works: Organizes data into child nodes (<thead>, <tbody>, <tr>, <td>), ensuring accessible reading of complex relationships.

When to use: Exclusively for representing two-dimensional tabular data (schedules, financial statements, metrics).

Syntax:

<table>...</table>

<caption>

Function: Provides a general title or explanatory description for a data table.

How it works: Positions as the first child node inside <table> and is prioritized by screen readers to contextually inform users.

When to use: On any table requiring an explanatory header or title.

Syntax:

<caption>Table 1: Pricing Plan Comparison</caption>

<thead>, <tbody>, <tfoot>

Function: Semantically separate the three essential areas of a table: header, main body, and summary footer.

How it works: Organize structural blocks allowing browsers to keep header rows fixed during long vertical scrolling.

When to use: In formal tables to organize structural sectors.

Syntax:

<thead>...</thead> <tbody>...</tbody> <tfoot>...</tfoot>

<tr>, <th>, <td>

Function: Build the inner grid framework of a table.

How it works: <tr> defines horizontal rows; <th> contains highlighted header cells; <td> stores data values.

When to use: To populate data intersections across rows and columns.

Syntax:

<tr><th>Name</th><td>John Doe</td></tr>

<colgroup> and <col>

Function: Define structural styles and properties for full columns within a table.

How it works: <colgroup> groups one or more <col> tags, enabling global application of classes or widths without repeating attributes across cells.

When to use: To style or format specific table columns centrally.

Syntax:

<colgroup><col class="highlighted-col"><col span="2"></colgroup>

INPUT

Forms and Data Capture

Interactive controls for collecting, validating, and submitting user information.

<form>

Function: Delimits a section of interactive controls to capture user input for processing or transmission.

How it works: Gathers input values and, upon submit execution, issues HTTP requests (GET/POST) to the URL defined in the action attribute.

When to use: In contact forms, login portals, registrations, and filters.

Syntax:

<form action="/process-data" method="POST">...</form>

<input>

Function: Represents the fundamental multi-purpose data capture field.

How it works: Alters its behavior, validation rules, and appearance based on its type attribute (text, password, email, checkbox, radio, file, etc.).

When to use: To capture short responses, credentials, single selections, or file uploads.

Syntax:

<input type="email" name="email" placeholder="example@web.com" required>

<label>

Function: Provides an explanatory descriptive label to a form control.

How it works: Binds text labels to target input fields using the for attribute matching the input id, expanding accessible click areas.

When to use: On all form controls without exception per accessibility standards.

Syntax:

<label for="full-name">Full Name:</label> <input type="text" id="full-name" name="name">

<textarea>

Function: Offers a multi-line input field for entering long text.

How it works: Allows users to write several lines of text with manual line breaks, adjustable via rows and cols attributes.

When to use: For comment sections, feedback forms, messaging, or descriptions.

Syntax:

<textarea name="comment" rows="4" placeholder="Type your message..."></textarea>

<select>, <option>, <optgroup>

Function: Allow constructing drop-down selection menus.

How it works: <select> wraps the drop-down, <option> defines selectable values, and <optgroup> categorizes related options.

When to use: To select countries, categories, or predefined values, reducing entry errors.

Syntax:

<select name="country"><optgroup label="Americas"><option value="cr">Costa Rica</option><option value="mx">Mexico</option></optgroup></select>

<button>

Function: Represents an executable interactive button within the interface.

How it works: Triggers form submissions (type="submit"), resets inputs (type="reset"), or invokes custom JavaScript functions (type="button").

When to use: For confirmations, dynamic actions, or form submissions.

Syntax:

<button type="submit">Submit Form</button>

EMBEDDING

Advanced Multimedia and Content Insertion

Elements for embedding video, audio, documents, external browsing contexts, and programmable graphics.

<video>

Function: Natively embeds video playback in the browser without requiring external plugins.

How it works: Uses internal browser decoders to process video files (MP4, WebM), with options to enable integrated controls (controls), autoplay, or loops.

When to use: To display tutorials, demonstrations, or animated backgrounds.

Syntax:

<video src="video.mp4" controls width="640" height="360">Your browser does not support the video tag.</video>

<audio>

Function: Embeds sound tracks, music, or audio streams directly into the document.

How it works: Processes auditory files (MP3, WAV, OGG) through a native control interface rendered on the page.

When to use: For podcasts, music tracks, or audio effects.

Syntax:

<audio src="podcast.mp3" controls>Your browser does not support audio elements.</audio>

<iframe>

Function: Inserts a nested browsing context loading another HTML document inside the current page.

How it works: Creates an isolated independent window downloading and running an external URL inside fixed dimensions.

When to use: To integrate interactive maps (Google Maps), external videos (YouTube), or third-party widgets.

Syntax:

<iframe src="https://maps.google.com/" width="600" height="450" loading="lazy"></iframe>

<embed>

Function: Acts as an integration point for external non-native applications or interactive content.

How it works: Calls browser plugins or external handlers to render interactive content like PDF documents or specific apps.

When to use: To embed external interactive files when <iframe> or <object> are unsuitable.

Syntax:

<embed type="application/pdf" src="document.pdf" width="500" height="300">

<object> and <param>

Function: Allows embedding generic external multimedia resources while accepting initialization parameters.

How it works: <object> loads resources based on MIME type and URL; nested <param> tags pass configuration variables to the loaded resource.

When to use: To embed complex media or widgets requiring setup arguments.

Syntax:

<object data="media.swf" type="application/x-shockwave-flash"><param name="autoplay" value="true"></object>

<canvas>

Function: Provides a real-time programmable bitmap drawing canvas.

How it works: Exposes a blank graphic area where JavaScript draws 2D shapes or 3D animations (WebGL) rendered pixel by pixel.

When to use: In browser-based 2D/3D games, dynamic data charts, or web image editors.

Syntax:

<canvas id="gameCanvas" width="800" height="400"></canvas>

INTERACTION

Interactivity and Dynamic Web Components

Native HTML elements for disclosure widgets, dialogs, templates, and reusable component structures.

<details> and <summary>

Function: Natively create collapsible disclosure widgets to show or hide information without requiring JavaScript.

How it works: Users click on <summary> (acting as the header), and the browser toggles visibility of the nested content inside <details>.

When to use: In accordion sections, FAQ boxes, or secondary information blocks.

Syntax:

<details><summary>What payment methods are accepted?</summary><p>We accept credit cards, debit, and bank transfers.</p></details>

<dialog>

Function: Represents a native modal window or popup dialog box.

How it works: Controlled via native JavaScript functions (showModal(), close()), managing visual overlays and backdrop page locking.

When to use: For modal confirmation boxes, custom alerts, or floating forms.

Syntax:

<dialog id="noticeModal"><p>Are you sure you want to delete this record?</p><button onclick="document.getElementById('noticeModal').close()">Cancel</button></dialog>

<template> and <slot>

Function: Allow storing HTML markup fragments that are not rendered on page load, serving as reusable templates.

How it works: <template> keeps fragments inert in memory until JavaScript clones and inserts them into the DOM. <slot> acts as a placeholder to inject content into Web Components.

When to use: For dynamic creation of product cards, table rows, or Web Component development using Shadow DOM.

Syntax:

<template id="card-item"><div class="card"><slot name="title">Default Title</slot></div></template>

ACCESSIBILITY

Web Accessibility and Narrative Regions

Accessibility semantics that communicate roles, states, and additional meaning to assistive technologies.

aria-* Attributes (e.g., aria-label, aria-hidden)

Function: Provide additional accessibility metadata to convey state, properties, and roles of elements to assistive technologies.

How it works: Modify the accessibility tree exposed by the browser; for example, aria-label sets a direct text label, while aria-hidden="true" hides elements from screen readers.

When to use: When native HTML structures do not fully convey the interactive or visual behavior of a component.

Syntax:

<button aria-label="Close window">X</button>

role Attributes (e.g., role="navigation", role="alert")

Function: Explicitly define an element's purpose or function within the accessibility tree.

How it works: Inform assistive reading tools about component types (e.g., an alert panel or navigable bar), overriding or reinforcing default semantic roles.

When to use: When building custom complex components using non-semantic elements like <div> or <span>.

Syntax:

<div role="alert">An error occurred while processing payment.</div>

GRAPHICS

Integrated Vector Graphics (SVG)

Native vector graphics that can be embedded and controlled through HTML and SVG markup.

<svg>

Function: Serves as the root container defining scalable vector graphics drawn via code.

How it works: Declares a 2D coordinate system where the browser renders resolution-independent geometric shapes, lines, and paths.

When to use: For logos, icons, interactive illustrations, or vector schematics.

Syntax:

<svg width="100" height="100">...</svg>

SVG Basic Shapes (<circle>, <rect>, <path>, <line>)

Function: Draw specific geometric shapes and vector paths inside an SVG canvas.

How it works: The browser processes coordinates and mathematical parameters assigned in attributes like cx, cy, r, x, y, d to draw lines, rectangles, circles, or complex paths.

When to use: To build custom graphics, icons, and illustrations directly in code.

Syntax:

<svg width="100" height="100"><circle cx="50" cy="50" r="40" fill="red" /></svg>

MATH

Mathematical Markup Language (MathML)

Native markup for representing structured mathematical notation.

<math>

Function: Represents the root container for native inclusion of complex mathematical notation and expressions.

How it works: The browser engine interprets the hierarchical element structure of MathML to format typography for equations, fractions, and radicals.

When to use: In scientific, educational, or mathematical documents needing accurately formatted formulas.

Syntax:

<math><mi>x</mi><mo>=</mo><mn>2</mn></math>

MathML Notation Components (<mrow>, <mfrac>, <msqrt>, <msup>)

Function: Structure and format advanced mathematical expression blocks.

How it works: Organize terms hierarchically; <mrow> groups rows, <mfrac> creates fractions, <msqrt> applies square roots, and <msup> places exponents or superscripts.

When to use: To compose readable, accessible algebraic formulas, fractions, and powers.

Syntax:

<math><mfrac><mn>1</mn><mn>2</mn></mfrac></math>
