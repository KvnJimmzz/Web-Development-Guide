JavaScript (JS)

03 TECHNOLOGY

JavaScript (JS) is the standard programming language used to bring interactivity, dynamic behavior, and control logic to web pages. Its primary function is to manipulate the DOM, manage user events, process data, and communicate asynchronously with web servers.

01

STRUCTURE

Base Structure and Language Insertion

<script> Tag (Internal)

Function: Serves to write and embed JavaScript code blocks directly within an HTML file.

How it works: The browser execution engine temporarily pauses parsing the HTML document, interprets, and executes the statements written inside the block immediately.

When to use: For small test scripts, brief initial configurations, or rapid prototyping.

Syntax: 

<script>console.log("Application initialized successfully.");</script>

<script src> Tag (External File)

Function: Serves to link an external executable JavaScript file (.js) to the HTML page.

How it works: The browser makes an independent network request to download the script file and processes its content separately from the HTML structure.

When to use: In most web projects to maintain a clean separation between structure and behavior.

Syntax: 

<script src="main.js"></script>

defer Attribute

Function: Serves to download the external script in the background without interrupting HTML parsing.

How it works: Instructs the browser to continue building the DOM and postpone script execution until the HTML document has been fully parsed.

When to use: On scripts that require all visual DOM elements to be loaded before executing.

Syntax: 

<script src="app.js" defer></script>

async Attribute

Function: Serves to download and execute a script asynchronously as soon as it becomes available.

How it works: Downloads the file in the background and pauses HTML parsing only for the exact time required to execute the downloaded code.

When to use: On independent scripts that do not rely on other files or the DOM structure, such as analytics or advertising tools.

Syntax: 

<script src="analytics.js" async></script>

"use strict" Directive (Strict Mode)

Function: Serves to restrict code execution to a safer, more rigorous variant of JavaScript.

How it works: Eliminates silent errors in the language by throwing explicit exceptions and disables obsolete or potentially unsafe syntax.

When to use: At the beginning of .js files or function blocks to prevent silent bugs and unintended global variables.

Syntax: 

"use strict"; x = 3.14;

02

VARIABLES AND CONSTANTS

Variables, Constants, and Scopes

let Declaration

Function: Serves to declare variables whose value can change over time, scoped to a block.

How it works: Creates a reassignable memory reference that only exists within the curly-brace-delimited block where it was declared.

When to use: For counters, accumulators, or state variables that require reassignment.

Syntax: 

let counter = 0; counter = counter + 1;

const Declaration

Function: Serves to declare read-only constants whose memory reference cannot be reassigned.

How it works: Locks direct reassignment of the variable within its block scope, ensuring the identifier always points to the same initial data or address.

When to use: By default for all variables, object references, arrays, and functions that do not require reference changes.

Syntax: 

const API_URL = "https://api.company.com/v1";

var Declaration

Function: Historical variable declaration with function scope or global scope.

How it works: Hoists its declaration to the top of the current scope via hoisting, ignoring the block scope of conditions or loops.

When to use: Not recommended in modern JavaScript; replaced by let and const.

Syntax: 

var name = "Carlos";

03

DATA TYPES

Primitive Data Types and Literals

String Type

Function: Represents and manipulates text sequences or strings.

How it works: Stores characters in UTF-16 format delimited by double quotes, single quotes, or template literals.

When to use: For names, descriptions, messages, and text-based interactivity.

Syntax: 

let user = "Ana"; let message = "Hello " + user;

Number Type

Function: Represents integer or double-precision floating-point numerical values.

How it works: Enables direct mathematical operations using the IEEE 754 64-bit standard.

When to use: For prices, indices, quantities, geometric calculations, or metrics.

Syntax: 

let price = 99.99; let quantity = 5;

BigInt Type

Function: Represents arbitrary-precision integers for values greater than the standard numeric limit.

How it works: Stores integers of unlimited size by appending an 'n' to the end of the number or invoking the BigInt constructor function.

When to use: For banking transaction identifiers, massive unique IDs, or cryptographic calculations.

Syntax: 

const hugeNumber = 9007199254740991n;

Boolean Type

Function: Represents a logical entity that takes only one of two values: true or false.

How it works: Models control flags and logical switches within conditional evaluations in code.

When to use: In state validations, permissions, or flow control conditions.

Syntax: 

let isActive = true;

null Value

Function: Indicates the intentional and deliberate absence of any object or value.

How it works: Assigns an empty reference to a variable to indicate that data has been cleared or purposefully initialized empty.

When to use: To deliberately reset variables or indicate empty results in search operations.

Syntax: 

let serverResponse = null;

undefined Value

Function: Indicates that a variable has been declared but not yet assigned a value.

How it works: It is the default value automatically assigned by the JavaScript engine to unprovided variables or parameters.

When to use: To verify if a variable has received an initial value or if a property exists.

Syntax: 

let unassignedData; console.log(unassignedData);

Symbol Type

Function: Creates unique and immutable identifiers to prevent name collisions.

How it works: Generates a completely unique key in memory guaranteed not to clash with any other object property.

When to use: To define private properties or meta-keys within complex objects.

Syntax: 

const uniqueId = Symbol("id");

04

DATA STRUCTURES

Complex Data Structures (Objects, Arrays, Map, and Set)

Object (Object)

Function: Serves to group collections of data using key-value pairs.

How it works: Models structured data by assigning property names to any computational data type or function.

When to use: To represent composite entities such as users, products, or configurations.

Syntax: 

const person = { name: "Elena", age: 28, city: "San José" };

Array (Array)

Function: Stores ordered lists of numerically indexed values.

How it works: Maintains sequences of data where each element occupies a zero-based position (0, 1, 2...), offering built-in methods to transform the list.

When to use: For item collections, task lists, or search results.

Syntax: 

const fruits = ["Apple", "Banana", "Orange"];

Map Structure

Function: Stores key-value pairs where any data type (including objects or functions) can be used as a key.

How it works: Maintains the original insertion order of elements and provides optimized operations for adding, searching, and deleting data.

When to use: When keys other than strings are required or when read/write operations occur with high frequency.

Syntax: 

const map = new Map(); map.set("id", 101); map.set(person, "Client");

Set Structure

Function: Stores collections of unique values of any type without duplicates.

How it works: Evaluates the uniqueness of inserted data and automatically discards duplicate elements.

When to use: To remove duplicate elements from arrays or maintain lists of unique identifiers.

Syntax: 

const uniqueValues = new Set([1, 2, 2, 3, 4, 4]);

05

OPERATORS

Arithmetic, Logical, Assignment, and Comparison Operators

Arithmetic Operators

Function: Perform basic mathematical calculations on variables and literals.

How it works: Processes addition (+), subtraction (-), multiplication (*), division (/), modulus or remainder (%), and exponentiation (**).

When to use: In any mathematical expression or incremental value updates.

Syntax: 

let total = (10 + 5) * 2; let remainder = 10 % 3;

Strict Comparison Operators (=== and !==)

Function: Evaluate equality or inequality between two operands by comparing both value and data type.

How it works: Directly compares both sides without performing implicit type coercion, returning a boolean value.

When to use: Always when performing logical comparisons to avoid bugs caused by automatic type conversion.

Syntax: 

if (age === 18) { console.log("Is of legal age."); }

Logical Operators (&&, ||, !)

Function: Combine or invert boolean condition evaluations.

How it works: The AND operator (&&) requires both conditions to be true; the OR operator (||) requires at least one to be true; the NOT operator (!) inverts the boolean value.

When to use: To construct complex conditions that evaluate multiple factors simultaneously.

Syntax: 

if (hasAccount && isConnected) { allowAccess(); }

Ternary Operator (? :)

Function: Provides concise single-line syntax to evaluate a condition and return one of two values.

How it works: Evaluates the expression on the left of the question mark; if true, it returns the first option; otherwise, it returns the option after the colon.

When to use: For direct variable assignments based on simple conditions.

Syntax: 

const status = age >= 18 ? "Adult" : "Minor";

Nullish Coalescing Operator (??)

Function: Returns the right-hand operand only when the left-hand operand is null or undefined.

How it works: Unlike the OR operator, it does not treat falsy values like the number 0 or empty strings as triggers to fall back to the default value.

When to use: To safely assign default values to optional variables.

Syntax: 

const limit = enteredLimit ?? 10;

Optional Chaining Operator (?.)

Function: Reads the value of a nested object property without causing an error if the preceding property is null or undefined.

How it works: Evaluates the prior reference; if it is null or undefined, evaluation stops and returns undefined instead of throwing an exception.

When to use: When accessing properties in network responses or objects with optional structures.

Syntax: 

const city = user?.address?.city;

06

FLOW CONTROL

Conditional Flow Control and Branching

if...else Statement

Function: Executes different blocks of code based on the evaluation of a logical condition.

How it works: Redirects execution flow to the if block if the condition evaluates to true, or to the else block if it evaluates to false.

When to use: For standard logical branching with multiple decision paths.

Syntax: 

if (score >= 90) { console.log("Excellent"); } else { console.log("Passed"); }

switch Statement

Function: Evaluates an expression against multiple matching cases to execute specific instructions.

How it works: Strictly compares a central value against each case label, jumping to the matching block until encountering a break or end statement.

When to use: When a single variable can take on multiple discrete values.

Syntax: 

switch (day) { case "Monday": console.log("Start"); break; default: console.log("Other day"); }

07

LOOPS

Loops, Iteration, and Generators

for Loop

Function: Repeats a block of code a set number of times using an explicit counter.

How it works: Initializes a control variable, checks a condition before each iteration, and updates the counter upon finishing the block.

When to use: When the exact number of required iterations is known beforehand.

Syntax: 

for (let i = 0; i < 5; i++) { console.log(i); }

while Loop

Function: Continuously executes a code block while a given condition remains true.

How it works: Evaluates the conditional expression at the start of each cycle; if positive, executes the internal instructions.

When to use: When the number of repetitions depends on an unpredictable dynamic event or state.

Syntax: 

while (connected) { listenForRequests(); }

do...while Loop

Function: Executes a code block at least once and continues repeating it while a condition remains true.

How it works: Runs the instructions inside the block first, then evaluates the condition at the end of each cycle.

When to use: When the block must run a mandatory initial execution before checking conditions.

Syntax: 

do { requestPassword(); } while (passwordInvalid);

for...of Loop

Function: Iterates directly over values of iterable data structures (Arrays, Strings, Sets, Maps).

How it works: Extracts the individual value from each position in every cycle without requiring manual index management.

When to use: To cleanly iterate over entire arrays or collections.

Syntax: 

const names = ["Ana", "Luis"]; for (const name of names) { console.log(name); }

for...in Loop

Function: Iterates over all enumerable properties of an object.

How it works: Loops through key names of an object during each iteration.

When to use: To inspect or iterate over internal keys of an object.

Syntax: 

const car = { make: "Toyota", model: "Corolla" }; for (const key in car) { console.log(key); }

08

FUNCTIONS

Functions, Parameters, and Expressions

Declared Function (function)

Function: Encapsulates a reusable code block with a named identifier for later invocation.

How it works: Registers the function in memory during the compile phase via hoisting, allowing it to be invoked before or after its physical declaration in the file.

When to use: To modularize recurrent tasks within core logic.

Syntax: 

function add(a, b) { return a + b; }

Expressed Function (const name = function)

Function: Assigns an anonymous function to a variable.

How it works: Treats the function as a value, preventing its use prior to the line where it is defined.

When to use: To isolate functions or pass them as arguments to other components.

Syntax: 

const subtract = function(a, b) { return a - b; };

Arrow Functions (=>)

Function: Offers concise syntax for writing functions while preserving lexical binding of the this context.

How it works: Declares an anonymous function using an arrow, omitting the function keyword and allowing implicit returns on single-line statements.

When to use: For callbacks, helper functions, and array transformations.

Syntax: 

const multiply = (a, b) => a * b;

Default Parameters

Function: Assigns default values to function parameters if no arguments are passed during invocation.

How it works: Checks if the passed argument is undefined; if so, assigns the preconfigured default value specified in the signature.

When to use: To avoid invalid or missing values when invoking functions.

Syntax: 

function greet(name = "Guest") { return "Hello " + name; }

ADVANCED FUNCTIONS

Advanced Functions, Closures, and Basic Asynchrony

Array Methods (map, filter, reduce)

Function: Process, transform, filter, and aggregate elements within an array.

How it works: Executes a callback on each element. map creates a new transformed array; filter creates a conditional subset; reduce aggregates data into a single final value.

When to use: To manipulate data collections without imperative loops.

Syntax: 

const numbers = [1, 2, 3]; const doubled = numbers.map(n => n * 2);

forEach Method

Function: Executes a provided function once for each element in an array.

How it works: Sequentially iterates through the list applying callback logic, without returning a new array.

When to use: For side effects (e.g., logging or database storage) on each element.

Syntax: 

numbers.forEach(num => console.log(num));

Closure Mechanism

Function: Allows an inner function to access the variable scope of an outer function even after the outer function has finished executing.

How it works: Retains a reference to its lexical environment created during definition, preserving the state of private variables.

When to use: To create private data, encapsulate logic, or generate specialized functions.

Syntax: 

function createCounter() { let c = 0; return function() { c++; return c; }; }

setTimeout Timer

Function: Schedules deferred execution of a function after a specified delay in milliseconds.

How it works: Hands off the specified function to the browser environment, executing it once the set timer expires.

When to use: For delayed actions, timeouts, or scheduled animations.

Syntax: 

setTimeout(() => { console.log("Time elapsed"); }, 1000);

setInterval Timer

Function: Repeatedly executes a function at fixed time intervals.

How it works: Fires the assigned callback cyclically until explicitly cleared.

When to use: For clocks, real-time polling, or recurring animations.

Syntax: 

const id = setInterval(() => { console.log("Repeating"); }, 2000);

clearInterval Function

Function: Stops periodic execution previously initiated by setInterval.

How it works: Accepts the unique timer ID returned by setInterval and cancels future callback execution in the browser engine.

When to use: To stop clocks, counters, or repeating processes when a condition is met.

Syntax: 

clearInterval(id);

DOM

DOM Manipulation and Node Traversal

document.querySelector Function

Function: Finds and retrieves the first HTML element in the document matching a specified CSS selector.

How it works: Traverses the DOM structure and returns a direct reference to the first node matching the search criteria.

When to use: To select specific individual elements by ID, class, or tag.

Syntax: 

const button = document.querySelector("#btn-save");

document.querySelectorAll Function

Function: Finds and retrieves all document elements matching a specified CSS selector.

How it works: Returns a static node collection (NodeList) containing all matching elements found.

When to use: To modify or iterate over multiple similar elements on the page.

Syntax: 

const items = document.querySelectorAll(".list-item");

textContent Property

Function: Reads or updates the plain text content of a node and its descendants.

How it works: Replaces inner text while removing any prior child nodes, without parsing HTML tags.

When to use: To safely update text labels without risks of code injection.

Syntax: 

document.querySelector("h1").textContent = "New Title";

innerHTML Property

Function: Reads or inserts parsed HTML content inside an element.

How it works: Interprets the assigned string as HTML markup and builds corresponding DOM nodes within the container.

When to use: To render complex dynamic element structures.

Syntax: 

document.querySelector("#container").innerHTML = "<p>New text</p>";

classList Object (add, remove, toggle)

Function: Manipulates CSS classes assigned to a DOM element.

How it works: Modifies the element class list by adding (add), removing (remove), or toggling (toggle) class presence without affecting other existing classes.

When to use: To dynamically update visual styles or UI states.

Syntax: 

element.classList.add("active"); element.classList.toggle("visible");

document.createElement Function

Function: Creates a new HTML element node in memory.

How it works: Generates a detached element structure ready to be configured and inserted into the DOM.

When to use: To construct visual elements prior to rendering them on screen.

Syntax: 

const newDiv = document.createElement("div");

appendChild / append Function

Function: Inserts a child node at the end of the child node list of a specified parent element.

How it works: Appends the new element into the active DOM, causing it to render on screen.

When to use: To render previously constructed elements on the page.

Syntax: 

document.body.appendChild(newDiv);

BROWSER EVENT MANAGEMENT

Browser Event Management and Propagation

addEventListener Method

Function: Registers an event listener on a DOM graphical element.

How it works: Listens for user interactions (clicks, keypresses, scrolls) and executes a function at the precise moment the action occurs.

When to use: To add interactive capabilities to buttons, forms, and visual elements.

Syntax: 

const btn = document.querySelector("button"); btn.addEventListener("click", () => { console.log("Click"); });

removeEventListener Method

Function: Removes a previously registered event listener from a DOM element.

How it works: Unbinds the assigned handler function, preventing it from executing during future trigger events.

When to use: To clean up memory resources or disable temporary user interactions.

Syntax: 

element.removeEventListener("click", handlerFunction);

event.preventDefault() Method

Function: Cancels the browser default action associated with a given event.

How it works: Interrupts native behavior (such as page reloading upon form submission or link navigation).

When to use: When validating form data using JavaScript prior to submission.

Syntax: 

form.addEventListener("submit", (e) => { e.preventDefault(); });

event.stopPropagation() Method

Function: Prevents event propagation to parent elements within the DOM tree.

How it works: Stops the bubbling phase of an event at the current node so parent handlers are not triggered.

When to use: To prevent inner element actions from triggering event handlers installed on ancestor containers.

Syntax: 

btn.addEventListener("click", (e) => { e.stopPropagation(); });

ASYNCHRONOUS PROGRAMMING

Advanced Asynchronous Programming, Fetch API, and AJAX

Promise Object

Function: Represents eventual completion or failure of an asynchronous operation.

How it works: Manages internal states (pending, fulfilled, rejected) and enables chaining response handlers.

When to use: To structure asynchronous operations such as network requests or data loading.

Syntax: 

const myPromise = new Promise((resolve, reject) => { resolve("Success"); });

.then() and .catch() Methods

Function: Process successful resolution or rejection of a Promise.

How it works: .then() receives fulfilled promise results, while .catch() captures errors occurring anywhere along the chain.

When to use: To handle asynchronous responses in traditional promise chains.

Syntax: 

myPromise.then(res => console.log(res)).catch(err => console.error(err));

async / await Keywords

Function: Write asynchronous code with syntax that resembles synchronous execution flow.

How it works: async implicitly wraps function returns in a promise, while await pauses execution inside the function until the promise resolves.

When to use: To simplify handling asynchronous network calls.

Syntax: 

async function load() { const res = await fetch("https://api.com"); }

fetch() Function

Function: Initiates HTTP network requests to query or send data to servers or APIs.

How it works: Issues requests using the Fetch standard and returns a promise resolving to the corresponding HTTP response.

When to use: To consume RESTful APIs, load JSON data, or interact with backend services.

Syntax: 

fetch("https://api.com/data").then(res => res.json());

OBJECT-ORIENTED

Object-Oriented Programming, Classes, and Prototypes

class Declaration

Function: Defines blueprints for creating objects using object-oriented programming concepts.

How it works: Acts as syntactic sugar over native prototype-based inheritance in JavaScript.

When to use: To model composite entities, UI components, or structures with associated data and behavior.

Syntax: 

class User { constructor(name) { this.name = name; } }

constructor Method

Function: Initializes object instance properties upon creation.

How it works: Executes automatically at the precise moment a class is instantiated using the new operator.

When to use: To assign required initial values to every newly created object.

Syntax: 

constructor(name, age) { this.name = name; this.age = age; }

extends and super Keywords

Function: Implement inheritance between classes to reuse parent class code.

How it works: extends establishes inheritance relationships, while super invokes the parent constructor.

When to use: To build specialized child classes derived from a base class.

Syntax: 

class Client extends User { constructor(name, id) { super(name); this.id = id; } }

EXCEPTIONS AND DEBUGGING

Error Handling, Exceptions, and Debugging

try...catch...finally Structure

Function: Catches and manages runtime failures without crashing the application.

How it works: Evaluates code inside the try block; if an error occurs, control transfers to catch. The finally block always runs at completion.

When to use: During external API calls, data parsing, or operations prone to runtime exceptions.

Syntax: 

try { JSON.parse("{ malformed }"); } catch (err) { console.log(err.message); }

throw Statement

Function: Generates an explicit custom exception or error.

How it works: Interrupts normal execution flow and passes control to the nearest catch block in the call stack.

When to use: To validate requirements or halt execution when data fails expected conditions.

Syntax: 

if (!age) { throw new Error("Age is required"); }

console Object (log, warn, error, table)

Function: Output messages, warnings, errors, and structured data into developer tools consoles.

How it works: Sends debugging information directly to browser or runtime developer tools.

When to use: During development to inspect variables and verify application flow.

Syntax: 

console.log("Message"); console.table([{ a: 1 }, { a: 2 }]);

ES MODULES

Modules and Code Architecture (ES Modules)

export Statement

Function: Exports functions, objects, classes, or variables from a JavaScript file for use in other modules.

How it works: Exposes selected elements outside the local file scope.

When to use: To build internal libraries, utility helpers, and modular components.

Syntax: 

export const calculate = (a) => a * 2;

import Statement

Function: Imports components or functions exported from other JavaScript modules.

How it works: Reads elements exposed by another file and incorporates their references into current local scope.

When to use: To integrate utility functions or components from separate files.

Syntax: 

import { calculate } from "./utilities.js";

LOCAL DATA

Local Storage, Cookies, and Persistence

localStorage Object

Function: Stores data persistently in the user browser without expiration dates.

How it works: Saves key-value pairs in plain text format directly inside the client browser.

When to use: To save user configurations, UI preferences, or persistent session tokens.

Syntax: 

localStorage.setItem("theme", "dark"); const theme = localStorage.getItem("theme");

sessionStorage Object

Function: Stores data temporarily in the browser for the duration of the active tab session.

How it works: Retains memory while the tab or window remains open, clearing all entries upon tab closure.

When to use: To store temporary form states or single-session navigation data.

Syntax: 

sessionStorage.setItem("step", "2");

document.cookie Property

Function: Reads or writes session cookies associated with the current domain.

How it works: Assigns formatted key-value strings alongside optional security and expiration parameters.

When to use: To store small session tokens required automatically on every HTTP request to the server.

Syntax: 

document.cookie = "user=Juan; expires=Thu, 18 Dec 2026 12:00:00 UTC; path=/";

17

REGEX

Regular Expressions (RegEx) and String Methods

RegExp Object

Function: Creates search patterns to validate or transform text strings.

How it works: Evaluates text sequences searching for pattern matches using methods like test or match.

When to use: To validate formatting on emails, phone numbers, or passwords.

Syntax: 

const pattern = /^[^\s@]+@[^\s@]+\.[^\s@]+$/; const isValid = pattern.test("email@test.com");

String Methods (includes, replace, slice)

Function: Search, replace, or extract text segments within a string.

How it works: includes verifies text existence; replace substitutes a matching segment; slice extracts a section of text.

When to use: To sanitize, format, or inspect text input.

Syntax: 

const text = "Hello World"; const sub = text.slice(0, 5);

ESNEXT

System APIs, Workers, and Modern Features (ESNext)

Destructuring

Function: Unpacks values from arrays or properties from objects directly into distinct variables.

How it works: Extracts keys from a structure, automatically assigning corresponding values to named variables.

When to use: To simplify accessing properties from configuration objects or API responses.

Syntax: 

const config = { port: 8080, host: "localhost" }; const { port, host } = config;

Spread Operator (...)

Function: Expands collection elements into a new destination.

How it works: Unrolls individual elements of an array or object into a newly initialized array or object.

When to use: To clone or merge objects and arrays without mutating original references.

Syntax: 

const original = [1, 2]; const copy = [...original, 3, 4];

Rest Parameter (...rest)

Function: Collects an indefinite number of arguments passed to a function into a single array.

How it works: Gathers remaining parameters into an array accessible within the function body.

When to use: In variadic functions accepting variable amounts of arguments.

Syntax: 

function sumAll(...numbers) { return numbers.reduce((a, b) => a + b, 0); }
